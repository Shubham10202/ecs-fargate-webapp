# AWS ECS Fargate Web Application

A hands-on AWS DevOps project that containerizes a Python Flask web application with Docker and deploys it to Amazon ECS Fargate using Amazon ECR.

## Architecture

**Current deployment flow:**

Developer → GitHub → Docker → Amazon ECR → Amazon ECS Fargate → Web Application

## Technologies Used

- **Python & Flask** — Web application and health endpoint
- **Docker** — Containerization
- **Amazon ECR** — Docker image registry
- **Amazon ECS Fargate** — Container orchestration without managing servers
- **AWS IAM** — Access control and task execution permissions
- **Amazon CloudWatch Logs** — Container log collection
- **Git & GitHub** — Version control and source code hosting

## Features

- Containerized Flask web application
- Custom dark-themed web interface
- Health-check endpoint at `/health`
- Docker image tagged `1.0`
- Deployment using Amazon ECS Fargate
- Container logs configured for Amazon CloudWatch

## Application Endpoints

| Endpoint | Purpose |
|---|---|
| `/` | Displays the web application |
| `/health` | Returns application health information in JSON |

Example health response:

```json
{
  "application": "ecs-fargate-webapp",
  "hostname": "container-hostname",
  "status": "healthy"
}
```

The hostname is generated by the running container.

## Run Locally with Docker

Clone the repository:

```bash
git clone https://github.com/Shubham10202/ecs-fargate-webapp.git
cd ecs-fargate-webapp
```

Build the Docker image:

```bash
docker build -t ecs-fargate-webapp:1.0 .
```

Run the container:

```bash
docker run -d --name ecs-webapp -p 5000:5000 ecs-fargate-webapp:1.0
```

Open `http://localhost:5000` in your browser.

Test the health endpoint:

```bash
curl http://localhost:5000/health
```

## AWS Deployment

1. Build the Docker image.
2. Push the image to Amazon ECR.
3. Create an ECS task definition.
4. Configure an ECS Fargate service.
5. Configure networking and security group rules.
6. Verify the running application and health endpoint.
7. Review container logs in Amazon CloudWatch.
